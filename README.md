# Riverside Clinic DevOps

This coursework project builds a controlled process for updating the fictional Riverside Community Clinic's website content.
The opening hours and service descriptions are invented examples, and no patient information is collected.
The project will demonstrate reviewed changes through branches and pull requests, automated content checks, and documented troubleshooting.
Its goal is to reduce content errors, make the process understandable to a second person, and provide a record of changes.
